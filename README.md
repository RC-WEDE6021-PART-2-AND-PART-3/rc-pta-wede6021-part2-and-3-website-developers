# Welcome! This project is set up so you can quickly run it on your own computer and see how everything works.

You can also view the live version here:
https://ai.studio/apps/ff8c3e23-0270-4d34-aaf0-39cbd0538ba0
## Run Locally

**Prerequisites:**  Before starting, make sure you have the following installed:

Node.js (this lets you run the project)

If you’re not sure whether you have it, open your terminal and type:
`node -v`

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

After a few seconds, you’ll see a local URL (something like http://localhost:3000) in your terminal

Open that link in your browser.
